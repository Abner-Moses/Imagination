## Project-created assets

- The training cone and training pole meshes are generated procedurally by this repository and have no external source.
- `assets/generated/cone_weathered_orange_albedo.png` was generated for this project with OpenAI's built-in image generation tool from the prompt recorded in the project work log. It is used only as a weathered orange-PVC material layer and contains no third-party artwork, logo, or text.
- Terrain geometry, grass-blade geometry, wear masks, material mixing, lights, trajectories, proxies and labels are generated by this repository.

The exact external metadata returned by Poly Haven, including descriptions, authors, publication dates and file hashes, is retained in `assets/third_party/polyhaven/manifest.json` after download.
